A three-dimensional simulation of an atmospheric sprite discharge, a type of low-temperature plasma discharge that appears high above intense thunderstorms.
The calculations were run using Cartesian AMR with Chombo, using approximately 4 billion grid cells.
The data shown uses the VisIt X Ray Image Query for ray-tracing the light emission from the sprite onto a reference aperture (just as regular cameras operate), permitting a direct comparison between simulations and optical observations from satellites or ground.
